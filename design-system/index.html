Kalibr8 (K8) · v1.0

One token set.
Two platforms.

Kalibr8 is an offline-first tool for disaster-relief UAV survey pilots. This design system themes both the responsive web app and the Android app from the same variables, text styles and components, which live in the Kalibr8 Figma file. Only the platform mode changes, adjusting sizes for touch and reading distance.

Use the Platform mode switch at the top to see every type style and component re-size between web and Android.

Semantic, not literal

Screens reference roles like color/primary, never hex values. Roles alias primitives, so a re-theme is one change.

Built for no signal

Offline is a normal state, so it's shown calmly in warning orange, not error red. Nothing loads from the network.

Colour is never the only signal

FEMA damage categories always show their label next to the colour, and status pills always carry text.

The pilot stays in control

Hold and Return Home stay on screen during autonomous flight, and every AI damage call shows whether a pilot verified it.

Foundations

Typography

Inter everywhere, bundled with the app so nothing loads offline. Style names follow Material 3 roles, and each style's size and line height come from the platform mode.

Foundations

Platform modes

The same token names have two values. Web uses desktop density; Android follows Material 3 with 48dp touch targets and at least 14sp body text.

Foundations

Spacing & radius

A 4-point spacing scale shared by both platforms. Buttons use radius/sm (4px) on Android too, a deliberate brand choice over Material's pill shape.

Corner radius

Foundations

Elevation

Three shadow levels. Dark surfaces get their depth mostly from the surface-container scale, with shadows as support.

Foundations

Icons

One icon set for both platforms on a 24×24 grid (Material Symbols geometry). Icons inherit colour from a color/* role. Size comes from size/icon.
